### 🧭 How I work

- **Data model first.** If the model is right, the rest of the app gets simpler.
- **Loading, error and empty states are features**, not afterthoughts.
- **Deploys you can repeat without surprises** — CI, infrastructure as code, one command.
- **Security by default:** Row Level Security, RBAC, schema validation, audit trails.
- **Tools for the problem, not for the hype.**
